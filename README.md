A drawn newspaper front page covering six supplied news reports from Wednesday
18 November 2026. Original bitmap lettering and geometric pictograms are rendered
directly into a 1024 × 1024 PNG, using only Python's standard library.
No photographs, external assets, network access, or randomness.

Run with Python 3.13:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image is written to `out/entry.png`. Without `MAKEFUN_OUTPUT_DIR`, the output
is `/output/entry.png`. The renderer and PNG encoder are contained in `main.py`.
